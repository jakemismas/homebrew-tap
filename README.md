# Homebrew tap for agent-balancer

This tap installs [agent-balancer](https://github.com/jakemismas/agent-balancer): a command line tool, a macOS menu bar app and a skill for anyone with several Claude Code accounts or subscriptions.

```
brew install jakemismas/tap/agent-balancer
```

The formula arrives with the first release. Until then, the command above finds no formula.
